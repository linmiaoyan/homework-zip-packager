# 作业压缩包收集工具（Flask Web 版）

将项目文件夹打包为 zip，并按课程要求自动命名：

**文档号 组长姓名 作品名称**

例如文档链接为 `https://note.ms/wzkjgz2` 时，文档号为 `2`，压缩包命名为：

`2 张三 XX游戏.zip`

## 启动方式

1. 双击 `run.bat`（或手动执行下面命令）

```bash
pip install -r requirements.txt
python app.py
```

2. 浏览器打开 [http://127.0.0.1:5000](http://127.0.0.1:5000)

## 使用步骤

1. 填写「文档链接 / 文档号」「组长姓名」「作品名称」
2. 页面会实时显示最终压缩包名称
3. 点击上传区域，选择整个项目文件夹
4. 点击「打包并下载」，浏览器会下载 zip，同时服务端保存到 `收集/` 目录

## 文档号规则

- 完整链接：`https://note.ms/wzkjgz2` → `2`
- 路径片段：`wzkjgz2` → `2`
- 纯数字：`2` → `2`

## API

- `POST /api/preview` — 实时预览命名
- `POST /api/pack` — 上传文件夹并打包
- `GET /api/collect` — 查看收集目录中的压缩包列表
