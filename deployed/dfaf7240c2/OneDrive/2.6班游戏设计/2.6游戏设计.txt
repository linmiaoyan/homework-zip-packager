对话选项式恐怖解谜游戏：《晚自习回魂》
定位：纯对话 + 选项推进｜高中校园微恐｜无血腥｜多结局｜适合高中生设计主角：你（高二学生）｜核心：被困深夜校园，通过对话 / 选择解谜、触发剧情、决定结局核心规则：全程无复杂操作，只有 **【选项】**，选不同答案→解锁不同线索 / 剧情 / 结局
一、游戏简介
你因为补作业留在教室，醒来时全校空无一人，门窗锁死，灯不停闪。不断出现模糊的提示、残留的声音、幻影对话，你只能通过选择回答 / 行动推进剧情。你要找回记忆、解开谜题，最终：逃脱｜被困｜和解。
二、完整剧情线（纯选项推进，三条分支）
【开场：醒来】
你趴在课桌上醒来。黑板上一行白字：“想走，就回答我。”突然出现对话选择：
“谁在那里？出来！” → 触发【紧张线】（恐怖氛围更强）
“我要回家，先找钥匙开门。” → 触发【解谜线】（优先找道具）
“这不是真的，我再睡一会。” → 触发【回忆线】（先解锁记忆碎片）
三、三大剧情线（全选项推进）
第一条线：紧张线（选 1）
走廊传来脚步声，你面前出现选项：
躲进课桌底下 → 听到对话：“你又躲起来…… 上次你也是这样。” 获得【日记碎片 1】
冲去走廊查看 → 灯全黑，三秒后出现纸条：“别找我，你会害怕”
大喊 “老师在吗？” → 广播响起：“晚自习已结束，清校” → 解锁【办公室路线】
继续选择：你拿到【后门钥匙】，来到卫生间。镜子出现模糊影子，弹出对话：“你还记得，约好要等我吗？”
“我记得！你是谁？” → 影子消失，获得密码【3-7-1】
“我没有约人！放我走！” → 水龙头疯狂滴水，门突然锁死
“我忘了…… 对不起” → 镜子出现字：去图书馆
第二条线：解谜线（选 2）
你决定先找钥匙，出现选项：
翻讲台抽屉 → 找到【值日表】，提示：最后值日生没走
看黑板粉笔字 → 得到线索：9:49
检查窗户 → 发现窗外有人影，但你打不开窗
来到办公室，电脑亮起对话：“输入密码，我告诉你她在哪。”
输 949 → 正确！获得【图书馆钥匙】
输班级号 → 错误，灯闪三下
乱输 → 电脑黑屏，弹出：你根本不在乎
进入图书馆，错题本自动打开：“你选：道歉 / 找她 / 离开”
道歉 → 进入【真结局前置】
找她 → 前往天台
离开 → 触发【坏结局】
第三条线：回忆线（选 3）
你闭眼回忆，脑海里出现对话：“那天晚自习，下雨了，你去哪了？”
我被老师留下了 → 解锁记忆：你撒谎了
我害怕被抓，不敢去 → 解锁完整记忆：你爽约了
我不记得了 → 头痛，出现幻影：同桌的背影
幻影开口：“你只要选一次，不丢下我就行。”
我陪你到雨停 → 触发【和解剧情】
我现在带你走 → 触发【逃脱剧情】
我还是想先走 → 触发【被困结局】
四、最终结局（由最后选项决定）
1. 真・和解结局（最佳）
选择：道歉 + 我陪你到雨停幻影消失，门打开。纸条：我不怪你。你成功走出校园。
2. 平安逃脱结局
选择：找她 + 带你走你解开所有锁，逃出大楼，但记忆永远缺失。
3. 遗憾被困结局
选择：离开 / 丢下我你永远留在 9:49 的教学楼里。
